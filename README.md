# Week 11 Lab: Classes and Objects

Practice defining a class, adding methods, and creating objects, then fix a broken class.

## Get started

- Review the assignment instructions and rubric in Blackboard.
- Open this folder in VS Code (not just the notebook), then open `week11_lab.ipynb`.
- Complete all four tasks. Keep your code and its output visible in the notebook.

## Submit your work

- Run all cells and save the notebook.
- Commit and push `week11_lab.ipynb` to this repository.
- Confirm the file appears online. If you revise your work, run all cells, save, and push again.
- Submit your repository link in Blackboard.

Full task instructions are included in `week11_lab.ipynb`.
